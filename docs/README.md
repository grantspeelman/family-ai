# Docs

What lives where. Whether a document may be committed is decided by the [rule in the conventions](conventions.md#what-goes-in-the-repo): architecture and engineering docs yes; pricing, positioning and anything commercially sensitive no.

| Path | What |
| --- | --- |

| [github-settings.md](github-settings.md) | GitHub settings the owner applies by hand, with the evidence and a record table for each. |
| [../first-build-pr-sequence.md](../first-build-pr-sequence.md) | The overall PR sequence and working notes (repo root). |
